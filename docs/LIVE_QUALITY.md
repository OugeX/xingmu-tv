## 落地改动

1. `assets/live_seed.json` 已重写：每个源写入 `measured_width/height/codec/fps/tier`，**频道内源按 4K → 1080p → 720p → … 排序**，频道加 `best_tier`/`best_height`（备份 `live_seed.json.bak`）。
2. 新增 `assets/live_hd.json`：只含实测 ≥1080p 的 **114 个频道**，用于界面里的「高清专区 / 4K 专区」分组。
3. 播放选源规则（t9 执行）：
   - 默认取该频道 `tier` 最高的源；失败按顺序降级（4K → 1080p → 720p），降级时提示「已切换到 1080p」。
   - 设备能力优先：`MediaCodec` 探测不支持 2160 时**不选 4K 源**，避免"选了播不动"。
   - 设置项「4K 优先」（默认关）：打开后允许 2160，仅对支持设备生效。
   - 换台/换源时把实测分辨率显示在 HUD（`1080p · 5.9Mbps · 硬解 H.264`），用户能看见自己看的是几档。
4. 码率参考（高码率 = 更清楚）：CGTN 系列 5.86Mbps、CCTV-9 4.72Mbps、伊犁经济法制 6.26Mbps，这些源已排在各自频道前列。

## 客观边界

- 公共单播源里 **真 4K 极少**（本次全网 2806 条候选只筛出 4 条 4K 源、3 个频道）。想要"每个台都 4K"，只能接运营商 IPTV 组播（`rtp://`/`udp://` + IGMP），那是另一条工程线，普通公网盒子拿不到。
- 你这台 X4-50 是 1080p 屏，4K 源会被缩放显示：**锐度会有提升但不是"4K 效果"**；且 4K H.264 25fps 老芯片可能解不动，所以默认不选 4K。
- 探测失败的 45 条源已标记，播放器不会优先选它们。
