# 老电视复活指南（安卓 TV / 电视盒子装星幕）

> 适用：2015 年以后、跑的动 APK 的安卓电视或盒子（**Android 5.0+**）。
> 已在 LeTV 超4 X50（Android 6 / MStar 6A938）上逐条验证；其他品牌路径类似。

## 0. 先确认三件事

| 检查 | 怎么查 | 不满足怎么办 |
| --- | --- | --- |
| 系统版本 ≥ Android 5.0 | 设置 → 关于 → 系统版本 | 低于 5.0 装不了（minSdk 21） |
| 能开「开发者选项 / USB 调试」 | 设置 → 关于 → 连点「版本号」7 次 | 部分运营商定制机锁了，见 §4 备用方案 |
| 电视和电脑在同一个 WiFi / 局域网 | 看两边的 IP 前三段是否一致 | 必须同网段，否则连不上 |

## 1. 打开电视的 ADB

各品牌路径不完全一样，找带「ADB / USB 调试 / 网络调试」字样的开关：

- **LeTV / 乐视**：设置 → 系统 → 开发者选项 → USB 调试（打开后默认监听 5555）
- **小米 / 红米**：设置 → 账号与安全 → ADB 调试（需登录小米账号）
- **华为 / 荣耀**：设置 → 关于 → 开发者选项 → USB 调试
- **TCL / 雷鸟**：设置 → 系统 → 开发者选项
- **创维 / 酷开**：设置 → 关于本机 → 开发者选项 → ADB 开关
- **索尼 / 原生 Android TV**：设置 → 设备偏好设置 → 关于 → 连点版本号 → 开发者选项 → USB 调试

记下电视的 IP（设置 → 网络 → 当前连接）。

## 2. 电脑这边准备 adb

Windows 最省事的方式：装 [Android SDK Platform-Tools](https://developer.android.com/studio/releases/platform-tools)，解压后在该目录开 PowerShell：

```powershell
adb connect 192.168.1.9:5555     # 换成你电视的 IP
adb devices                       # 看到 "<ip>:5555  device" 才算成功
```

连不上时依次试：
1. `adb kill-server` 再 `adb connect` 重连；
2. 换 `adb connect <ip>:5555` 为 `adb connect <ip>:4321`（部分盒子用这个端口）；
3. 关掉电视的「AP 隔离 / 访客网络」，很多路由器默认隔离设备间通信。

## 3. 安装

```powershell
adb install -r xingmu-tv-v0.2.4-08b76370.apk
```

装完在电视桌面上找 **星幕**（金色图标）。找不到就：
- 电视桌面 → 我的应用 / 全部应用；
- 或者在电脑上直接启动：`adb shell am start -n com.tvbox.app/.MainActivity`。

## 4. 首次配置（3 分钟）

1. **源**：默认已内置 7 个演示源，打开就能用。
   想加自己的源 → 侧栏「播放源」→ 手机扫码（电视会显示二维码和 6 位配对码），手机在网页里粘贴 JSON / 传文件 / 填地址即可，不用遥控器打字。
2. **直播**：侧栏「直播」，`CH+/CH-` 切台，`MENU` 呼出频道列表（含「高清专区」）。
3. **显示**：侧栏「设置 → 显示」
   - 觉得字小 → **大字号模式**（1.3×，近视/老花友好）
   - 画面被切边 → **过扫描补偿** 2.5% 或 5%
   - 机器很老很卡 → **C 保命模式**（纯黑高对比、零动画）

## 5. 常见问题

**Q：点开某些直播频道是黑屏？**
A：那类频道只有 1080p 源，而部分老芯片（MStar 6A938 等）的 1080p 解码路径本身不可用。App 已自动进入 **720p 安全档**并默认过滤这些频道；按 `MENU` 可以看到它们，但会提示「本机可能黑屏」。这不是 App 的 bug，是硬件解码能力的边界。

**Q：切台要等 1–2 秒？**
A：取决于源所在 CDN 的首片响应。快 CDN（CCTV 系列新源）实测 584ms，慢 CDN 会到 2 秒以上。App 会优先选实测更快的源。

**Q：详情页有时候要等好几秒？**
A：第一次打开某部作品要回源站取详情，慢的时候 2–7 秒（源站 TLS 冷连接）；打开过就会走缓存（实测 18ms）。

**Q：遥控器没有数字键，能搜片吗？**
A：可以。搜索页支持**首拼**：输入 `lldq` 就能出「流浪地球」。也可以按语音键（若系统支持识别）。

**Q：装完占多少空间？**
A：APK 12.4MB，安装后约 30MB；不依赖 Google 服务框架。

## 6. 卸载

```powershell
adb uninstall com.tvbox.app
```

## 7. 完全关不掉电视？

这不是 App 的问题，但顺手记一个坑：部分 LeTV 机型用 `adb shell reboot -p` 只会**重启**（固件会自动拉起），Android 层的电源键事件也会被 launcher 拦截。可行的是从内核输入层注入一次电源键：

```bash
adb shell "sendevent /dev/input/event4 1 116 1; sendevent /dev/input/event4 0 0 0; \
           sleep 0.2; \
           sendevent /dev/input/event4 1 116 0; sendevent /dev/input/event4 0 0 0"
```
`event4` 用 `getevent -pl` 查（找带 `KEY_POWER` 的设备），`116` 是 `KEY_POWER`。
