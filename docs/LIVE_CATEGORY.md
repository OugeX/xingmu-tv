# 直播频道分类展示（v0.3.4）

问题：266 个频道平铺在一个浮层列表里，太长，找台靠一直按。

## 1. 结构

```
┌ 分组 Tab（横向 chips，LEFT/RIGHT 切换）
│   高清专区(114) · 央视(24) · 卫视(17) · 地方(122) · 收藏 · 最近
├ 组内列表（两列网格，一屏 12–16 台，比单列快 2 倍）
│   台号  台名           线路数/清晰度
└ 底部提示：数字键直达 · 长按 OK 收藏 · MENU 显示全部
```

- 分组来源：`live_seed.json` 的 `group_id`（`cctv`/`satellite`/`local`/`hk_mo_tw`/`other`）+ 虚拟组「高清专区」（`live_hd.json`）、「收藏」、「最近」。
- **安全模式**下分组计数只算 `has_safe=true` 的频道（例：央视 24/28），避免"点进去少一半"的错觉。
- 「最近」保留最近 10 个看过的台，置顶；「收藏」长按 OK 添加/取消，存 SharedPreferences。

## 2. 组内网格

- 两列（大字号档 1 列；C 模式 2 列纯文字），每格：台号 + 台名 + 右侧小标签（`720p` / `3线` / `可能黑屏`）。
- 焦点移动：`LEFT/RIGHT` 换格，`UP` 到顶部后焦点跳分组 Tab，`DOWN` 到底部不越界。
- 组内超过 60 台时启用分页签（`1-60 / 61-120`），避免长列表；地方组 122 台会用到。

## 3. 快速定位

- **数字键直达**：输入台号（1–3 位）后自动过滤并聚焦；`OK` 确认播放，3 秒无输入自动清空。
- **首拼过滤**：分组 Tab 右侧一个「搜台」入口，输入 `hunan`/`hnws` 之类过滤台名（复用搜索页首拼索引）。
- 过滤态下分组 Tab 变灰，`BACK` 退出过滤回到分组视图。

## 4. 行为不变的部分

- 切台防抖 800ms、CH+/CH-、失败按 priority 试 ≤3 条备用源、全失败跳下一个台。
- 安全模式下自动跳过 `has_safe=false` 的频道；`MENU` 切「显示全部」时这些台带「可能黑屏」角标 + 播放前二次确认。
- 焦点预览即切台（当前行为）保留，但**分组切换不触发播放**。

## 5. 验收

| 项 | 标准 |
| --- | --- |
| 分组 Tab | 6 组切换正确，计数与安全模式一致 |
| 网格 | 两列、一屏 ≥12 台；焦点不越界、不回桌面 |
| 数字直达 | 输入 `5` → CCTV-5；错误台号提示「无此台号」 |
| 收藏/最近 | 长按 OK 收藏可见；最近 10 台按时间倒序 |
| 性能 | 切分组 ≤100ms（不重建播放器）；组内滚动掉帧 ≤10% |
