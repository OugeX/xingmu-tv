# UI 打磨清单（v0.3.1）

真机反馈三条：**分类不好用、分类内的详情页体验差、C 保命模式太简陋**。逐条给可执行改法，全部以现有令牌体系为准（不引 Material3、不加动画预算）。

## 1. 分类页（CategoryScreen）

现状：一行 chips + 网格 + 页脚，缺少层级和筛选，用户不知道自己在哪一层、也不知道能筛什么。

### 1.1 结构重排（三层）

```
┌ 顶部：电影 · 剧集 · 动漫 · 综艺 · 海外 · 短剧（一级 Tab，焦点行）
├ 二级：全部 / 动作 / 喜剧 / 科幻 …（子分类 chips，横向可滚）
├ 筛选：年份 全部/2026/2025/2024 · 地区 全部/大陆/港台/日韩/欧美 · 排序 最新/最热/评分
├ 面包屑：电影 › 动作片 · 已加载 120 条（右对齐）
└ 网格：6 列（大字号 4 列，C 模式 2 列）
```

- 一级 Tab 与左侧导航联动：从侧栏进「电影」时，一级 Tab 停在「电影」；在页内切 Tab 不改侧栏高亮（避免双重高亮）。
- 筛选行做成可聚焦的胶囊按钮，`OK` 弹出选项浮层（不要用下拉框，遥控器不好点）。
- 三种筛选都生效时，面包屑显示 `电影 › 动作片 · 2026 · 大陆 · 最新`。

### 1.2 卡片信息增强
- 海报右下：评分角标（有评分才显示，金色描边）
- 海报左下：`更新至 N 集` / `HD`（超长省略）
- 标题下一行：`2026 · 动作 · 3 源`（有源数才显示）
- 焦点态：3dp 金边 + 轻微放大（C 模式不加放大）

### 1.3 加载与空态
- 首屏：6 个骨架卡（灰块 + 微光，1200ms 一次，不做无限动画）
- 分页：滚动到倒数 8 项触发；页脚三态互斥（加载中 / 加载更多 / 没有更多了，失败单独显示重试按钮）
- 空态：「这个分类暂时没有内容」+「换个子分类」按钮（回退到全部）

## 2. 详情页（DetailScreen）

现状：Hero + 信息 + 选集，信息密度低，长剧选集难找，缺"下一步该看什么"。

### 2.1 首屏（不滚动就能看全关键信息）
- 左：竖版海报 300×420（C 模式 180×252），带 3dp 描边；**必须有占位兜底**（加载失败显示片名首字，不能用黑块）
- 右：标题（最大 2 行）→ 评分/年份/地区/时长 → 演员（1 行）→ 简介（3 行 + 展开）→ 按钮组
- 按钮组顺序：`▶ 播放第 N 集`（金色，自动取上次进度）、`＋ 收藏`、`切换源 (N)`、`更多`
- 右上角固定：`源：暴风` + `1080p` 角标

### 2.2 选集（长剧友好）
- 每行 8 个（C 模式 6 个），60 集以上按 30 集分页签
- **新增集数直达**：选集区右侧「跳到第 __ 集」按钮 → 数字键盘浮层（遥控器输 3 位数字）
- 已看打 ✓、当前集金底、未更新置灰
- 长按 OK：`从第 N 集播放 / 标记已看 / 复制集名`

### 2.3 相似推荐（新增）
- 详情页底部一行「同分类推荐」（取同 `type_id` 前 8 部，排除自己），卡片复用 PosterCard
- 数据来源：现有 `SourceRepository.list(typeId, page=1)`，不新增接口

### 2.4 滚动与返回
- 滚动时顶部收成窄条（标题 + 播放按钮常驻），返回键回到来源页（分类页保留滚动位置）

## 3. C 保命模式（LITE）

现状：纯黑 + 文字列表，被用户评价"太简陋"。目标：**在零动画、零阴影、低解码预算下也要有层次**。

### 3.1 允许的最小视觉元素（不违反性能约束）
| 元素 | 允许 | 说明 |
| --- | --- | --- |
| 缩略图 | ✅ 96×128（列表）/ 240×135（推荐条） | 仍受 `allowRgb565` + `Precision.INEXACT` 约束 |
| 分割线 | ✅ 1dp `#1E1E1E` | 已有 |
| 背景层次 | ✅ 两档：`#000` 底、`#0D0D0D` 卡片 | 已有 |
| 焦点态 | ✅ 左侧 4dp 红条 + 背景 `#141414` | 取消放大/发光 |
| 圆角 | ❌ 保持直角 | 省一次 clip 绘制 |
| 动画 | ❌ 无 | 包括 crossfade |

### 3.2 首页（C）
```
┌ 星幕 · 保命模式          源 3/3 · 19:02
├ [推荐条] 240×135 缩略图 + 片名 + 「▶ 继续观看 第 12 集」
├ 最新更新（两列文字列表，每行：序号 缩略图 片名/副标题 集数标签）
├ 直播（一行 4 个台标 + 台名，OK 直接起播）
└ 底部状态栏：硬解 H.264 · PSS · 缓存 · 按键提示
```

### 3.3 分类页（C）
- 一级 Tab 与筛选用单行文字胶囊（无边框，选中红字 + 下划线）
- 列表两列，每行高度 96dp（缩略图 96×128 会超，改成 72×96）
- 右侧留 40dp 空白给滚动条视觉平衡

### 3.4 详情页（C）
- 左 180×252 海报 + 右侧信息（标题 24sp、元信息 15sp、简介 3 行）
- 选集 6 列 chips，高度 56dp
- 不做 Hero 大图（省一次大图解码）

### 3.5 播放 HUD（C）
- 底部 312dp 半透明条：进度条 8dp、按钮 4 个（⏪ ⏯ ⏩ 选集），文字 15sp
- 不显示渐变遮罩，用纯色 `#000` 90% 底

## 4. 验收

- 真机（LeTV API23 / Konka API21）截图：分类页三层结构、详情页首屏、C 模式首页
- 静态：`lintDebug` 0 Error；列表 `key`/`contentType` 覆盖不退化
- 性能不退化（按内存当量而非张数）：
  - A 模式：单屏 ≤8 张 320×450
  - C 模式：单屏 ≤12 张 **72×96** 缩略图（≈3 张 240×135 的内存当量，故不冲突）
- 筛选说明：v0.3.1 的年份/地区/排序为**本地筛选**（作用于已加载分页，切换筛选时自动预取 3 页）；服务端筛选需扩 `SourceRepository` 契约，排 v0.3.2
