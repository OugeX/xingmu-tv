## 星幕 TV v0.3.1（UI 打磨）

### 分类页：三层结构
- 一级 Tab：电影 / 剧集 / 动漫 / 综艺 / 海外 / 短剧（短剧 type_id 58 已用线上接口核实）
- 二级子分类 chips + 筛选胶囊（年份 / 地区 / 排序，OK 弹浮层，不用下拉框）
- 面包屑：`电影 › 动作片 · 2026 · 大陆 · 最新` + 「已加载 N 条」
- 卡片增强：评分角标、更新集数/HD、「年份·子分类·N 源」
- 页脚三态互斥（加载中 / 加载更多 / 没有更多了 / 失败重试）、首屏 6 个骨架卡
- 说明：本版筛选为**本地筛选**（作用于已加载分页，切换筛选自动预取 3 页）；服务端筛选需扩 `SourceRepository` 契约，排 v0.3.2

### 详情页
- 首屏重排：海报 300×420（C 模式 180×252，**失败显示片名首字兜底**）、标题 2 行、评分/年份/地区/时长、演员 1 行、简介 3 行 + 展开
- 按钮顺序：`▶ 播放第 N 集` → `＋ 收藏` → `切换源 (N)` → `更多`
- 选集：60 集以上分页 + 「跳到第 __ 集」数字键盘浮层
- 底部新增「同分类推荐」8 部（排除自己）
- 返回保留分类页滚动位置

### C 保命模式（重点）
- 首页：推荐条（240×135 + 继续观看）+ 两列列表（行高 96dp、72×96 缩略图、左侧红条焦点）+ 直播一行 4 台 + 底部状态栏
- 分类页：文字胶囊 + 两列列表 + 右侧 40dp 留白
- 详情页：无 Hero 大图（省一次大图解码），左海报右信息 + 6 列选集
- 播 HUD：纯色 90% 底条 + 8dp 进度 + 4 个按钮
- 全模式无圆角 / 无动画 / 无阴影
