# UI 设计规范（已由老大定稿：A 主视觉 + C 保命模式）

> 本文件是 UI 的唯一权威。`docs/PLAN_ARCHITECTURE.md` 只管性能预算与工程约束；视觉与布局冲突时以本文件为准。
> 参考图：`design/mockups/A_cinema.png`（主模式）、`design/mockups/C_minimal.png`（低配模式）。

## 0. 双模式总则

| 模式 | 触发 | 布局 | 渲染预算 |
| --- | --- | --- | --- |
| **A 影院模式**（默认） | `PerfProfile.tier >= TIER_MID` | 左图标导航 + 大 Hero 剧照 + 海报横排/网格 | 单屏解码 ≤ 8 张（320×450 目标尺寸，硬件位图 + RGB565） |
| **C 保命模式** | `RAM < 1.5GB` 或 `lowRamDevice` 或 `SDK < 23` 或 首帧 > 2.5s 或 连续 2 次掉帧 > 30% | 纯黑 + 文字列表 + 小缩略图（112×63） | 单屏解码 ≤ 3 张，无渐变/阴影/动画/crossfade |

两模式共用同一套数据层、路由、播放器，只切换 `TvTheme` 与列表项 Composable。**禁止写两套业务逻辑。**

## 0.5 屏幕适配（硬要求，不满足算未交付）

**基线：960dp × 540dp**（Android TV 官方 1080p 设计基线）。所有尺寸一律用 dp/sp，**代码里禁止出现 px 写死**；设计稿按 `px ÷ density` 落值。

| 分档 | widthDp | 列数 | 视觉比例 |
| --- | --- | --- | --- |
| 小屏/老盒子 | < 800 | 4 列 | 0.85×（并强制 C 保命模式，见下） |
| 720p | 800–1199 | 5 列 | 0.9× |
| 1080p | 1200–1599 | 6 列 | 1.0× |
| 4K | ≥ 1600 且 density ≥ 2 | 6 列（同 1080p 布局） | 1.0×，仅图片请求尺寸 ×density |

- **类型缩放**：`baseScale = clamp(widthDp / 960f, 0.85f, 1.15f)`，标题字号乘 `baseScale`；再叠乘系统 `fontScale`（clamp 0.85–1.3，防止用户把字体调到爆版）。
- **Hero 高度** = `screenHeightDp × 0.59`，clamp 240–640dp；**不许写死 640dp**。图片用 `ContentScale.Crop` + 中心偏移，不随宽高比拉伸。
- **安全区/过扫描**：默认左右 48dp、上下 27dp；设置页提供 0% / 2.5% / 5% 三档 overscan 补偿（老电视必须能调，否则四边被切）。
- **4K（3840×2160, dpi 320+）**：widthDp 仍是 960 → 布局与 1080p 完全一致，只把 Coil 请求尺寸与 memoryCache 上限按 density 提升（海报 200dp→600px 请求），并启用 `allowHardware` 硬件位图避免 4K 解码爆内存。
- **非 16:9**（21:9 / 16:10 / 4:3）：行数由可用高度派生，不写死行数；直播页右侧播放器按可用高度自适应，不裁画面。
- **540p 及以下 / `Configuration.smallestScreenWidthDp < 600`**：直接进 C 保命模式。
- **最小可读字号**：辅助信息 ≥13sp，正文 ≥15sp，列表主标题 ≥17sp（2–3 米观看距离实测下限）。
- **交付验证**：必须给出 1280×720、1920×1080、3840×2160、960×540 四档实机/模拟器截图与对应列数；缺一档视为未完成。

## 0.6 大字号模式（近视 / 老花 / 视力疲劳，必做）

> 触发场景：用户距电视 1.5 米仍觉得字模糊。这不是"调大字体"一个开关能解决的——**字号、密度、对比度、焦点、字幕必须一起改**，否则字大了但信息更乱，反而更难读。

**三档，独立于 A/C 显示模式（可叠加）：**

| 档位 | 字号倍率 | 每行卡片 | 说明 |
| --- | --- | --- | --- |
| 标准 | 1.0× | 6 列（1080p） | 默认 |
| **大字** | 1.3× | 4 列 | **近视用户推荐档** |
| 超大 | 1.6× | 3 列 | 老花/远视/大客厅 |

在同一套令牌上，三档同时生效的规则：

1. **字号**：标题、卡片名、正文、辅助信息全部 × 倍率（不是只放大标题）。辅助信息（时长/评分/角标）低于 15sp 时直接**隐藏**而不是缩小，避免糊成一片。
2. **密度**：卡片列数按 6 → 4 → 3 递减，卡片变宽变高，标题最多 2 行全显示（标准档是 1 行截断）。
3. **对比度**：文字用纯白 `#FFFFFF`，背景压到 `#000000`，边框/分隔线加粗到 2dp（标准是 1dp），禁用半透明文字（`textMuted` 一档统一提亮到 `#B8B0A6`）。
4. **焦点**：描边 3dp → **5dp**，光晕扩大 1.5×，并增加**整卡片亮度提升**，让"当前在哪"一眼看清。
5. **图标与按钮**：左侧导航图标 44dp → 56dp，按钮最小高度 64dp，遥控器焦点命中区域不小于 72×72dp。
6. **播放器 HUD**：进度条 6dp → 10dp，播放/快进按钮 1.3×，标题字号 38sp → 52sp，选集面板每行 8 → 6 个且每格加高。
7. **字幕**：字幕字号 3 档（100%/130%/160%）+ 强制描边/半透明底衬（`TextStyle` + `setApplyEmbeddedStyles(false)`），只对流内自带字幕轨生效；烧录进画面的字幕无法调整（在设置里明确写清）。
8. **入口**：`设置 → 显示 → 大字号模式`，三档单选，**遥控器可实时预览**（切换后立刻刷新当前页，不需要重启）；另提供快捷键 `长按 MENU` 临时切换（再长按还原），方便老人误操作后恢复。
9. **持久化**：写入 SharedPreferences，随 `TvTheme` 一起在启动时生效，冷启动首帧就是用户选的档位，不允许先小后大闪一下。

**实现落点**：`TvDimens` 增加 `fontScaleTier`，所有 sp 走 `sp × tier`；卡片列数由 `columns = when(tier){ STANDARD->6; LARGE->4; XLARGE->3 }` 决定，**不要**用系统 `fontScale` 硬顶（系统字体放大只影响文字，不影响列数，会挤爆布局）。

### 1.3 焦点态（两模式通用规则，颜色不同）

- 焦点 = 3dp 描边 + 4dp 外扩 + 轻微放大（A：`scale 1.04` 仅卡片；C：不缩放）
- 焦点移动动画：A 模式 120ms 线性；C 模式 0ms
- **禁止**焦点态使用模糊/毛玻璃（低端 GPU 合成开销不可控）
- 失焦元素不透明变化超过 20%，避免大面积重绘

## 2. 全局导航

- A 模式：左侧固定 130dp 竖向图标栏（推荐/电影/剧集/动漫/综艺/**海外**/直播/播放源/搜索），选中项为金色描边图标 + 金色文字。
- C 模式：左侧 340dp 文字菜单（推荐/电影/剧集/动漫/综艺/海外/直播/播放源/搜索），选中项 = 红色 4dp 左边条 + 白字加粗 + `#0E0E0E` 底。
- 顶部右侧永远显示：当前时间、在线源数量（`源 3/3`）。C 模式下放到底部状态栏。

## 3. 页面规格

### 3.1 首页（A）

`LazyVerticalGrid(columns = 6)`，整屏纵向滚动：

1. **Hero**（span 全宽，高 640dp）：背景为详情页 `vod_pic_slide`/`vod_pic` 大图 + 双层渐变遮罩（上 35% 淡出、下 82% 渐入 bg）；左上角角标「正在热播 / 今日推荐」；标题 86sp；元信息行（年份 · 分类标签 · 集数 · 评分金色加粗）；简介最多 2 行；按钮组：`▶ 立即播放`（金色实心）、`＋ 收藏`（半透明描边）、`选集`。数据取 `ac=detail&pg=1` 首条或 `h=24` 第一条，10 分钟轮换一次。
2. **继续观看**（横排 4 张 16:9）：来自本地进度表，无数据时整行隐藏。
3. **热门电影 / 最新剧集 / 动漫热播 / 综艺更新**（每行 6 张海报 320×450 + 名 + 副标题）：分别对应 type_id `20 / 30 / 39 / 45`，`ac=detail&t=<id>&pg=1`。
4. 行标题右侧放「更多 ›」，点击进入对应分类网格页。

### 3.2 首页（C）

纯文字两列「最新更新」（电影/剧集 | 动漫/综艺），每行：序号 + 112×63 缩略图 + 名称 + 副标题 + 集数标签；底部状态栏显示解码方式、PSS、缓存大小、源在线数、按键提示。

### 3.3 分类网格页

- 顶部：子分类 chips（来自 `class` 树，`type_pid` 过滤）+ 排序切换（最新 / 最热）。
- 主体：A 模式 6 列海报网格 / C 模式 2 列文字列表。
- 分页：滚动到倒数第 12 项触发下一页；单页 20 条；到底显示「没有更多了」；失败显示「重试」按钮 + 错误码。
- 顶部常驻面包屑：`电影 › 动作片`。

### 3.4 详情页

- 顶部 40% 高度 Hero：背景图 + 渐变；标题、评分、年份、地区、语言、时长、演员（最多 2 行）。
- 简介可展开（默认 4 行）。
- 选集区：网格 chips（每行 8 个），当前集高亮金色；多线路时先显示线路 Tab（`vod_play_from` 按 `$$$` 拆分）。
- 底部按钮：`▶ 播放`、`＋ 收藏`、`切换源`（同名片源聚合，来自 `tvapp.source.v1` 多站）。

### 3.5 播放器 HUD

**播放页必须全屏（硬要求）**：进入播放即进入沉浸式全屏——`SurfaceView` 铺满屏幕、隐藏系统状态栏与导航栏（API 23 用 `SYSTEM_UI_FLAG_IMMERSIVE_STICKY | FULLSCREEN | HIDE_NAVIGATION | LAYOUT_FULLSCREEN | LAYOUT_HIDE_NAVIGATION`，API 30+ 用 `WindowInsetsController`）、左侧导航栏整体隐藏、无任何常驻列表。视频多余区域留黑边，不允许拉伸变形（`RESIZE_MODE_FIT` 默认）。

- HUD 是**浮在视频之上的覆盖层**，不挤占画面；进入 3s 后自动隐藏；任意按键唤出。
- 顶部：标题 + 集数 + 当前源名。
- 中部：进度条（直播模式隐藏，改为「LIVE」角标）。
- 底部：`⏪10s` `⏯` `⏩10s` · 倍速（0.75/1.0/1.25/1.5/2.0）· 画面比例（适应/拉伸/原始）· 选集 · 切源 · 解码信息（硬解/软解 + 分辨率 + 码率）。
- 选集面板、切源面板、清晰度面板都是**全屏之上的半屏抽屉**，呼出时视频继续播放不暂停、不缩小。
- 缓冲态：居中转圈 + 「正在缓冲 x%」；连续 8s 无数据自动切备用源并提示「已切换到备用线路」。
- 记忆播放：退出保存 position，下次进入弹「继续观看 / 从头播放」。
- 退出播放（BACK）才回到详情页，不允许播放页出现分栏布局。

### 3.6 直播页

**直播也是全屏播放**，频道列表是**按需呼出的浮层**，不是常驻分栏：

- 进入直播页：直接全屏播放上次频道；左侧 320dp 频道浮层默认隐藏。
- `LEFT` 或 `MENU` 呼出频道浮层（半透明，视频继续播、不暂停），再按 `LEFT`/`BACK` 收起。
- 浮层内：分组折叠（央视 / 卫视 / 地方 / 港澳台 / 其他 + 最近 / 收藏），`DPAD_UP/DOWN` 移动即预览切台（800ms 防抖），`CH+/CH-` 直接上下台，数字键直达台号，`OK` 确认并收起浮层。
- 频道信息卡（台标、分组、分辨率、码率、备用线路数、简介、EPG 正在播/下一档）在浮层右侧联动的详情区展示。
- C 模式：全屏播放 + 文字频道浮层（无缩略图、无动画），或用户可切「纯列表模式」。
- 切台失败：按 priority 试该频道 ≤3 条备用源，全失败提示「该频道暂不可用」并自动跳到下一个可用频道，画面停留在浮层不上黑。
- 频道列表来源：内置 `assets/live_seed.json`（266 频道 / 332 源）+ 用户导入 m3u。

### 3.7 搜索页

> 完整规则见 `docs/SEARCH_SPEC.md`：语音三层降级、首拼/全拼本地索引（FTS4 + `assets/pinyin_*.json`）、分段 Tab 与同片合并。

- 电视友好键盘：三态（数字 / T9 / QWERTY），长按数字出候选，`BACK` 逐字删。
- 输入 300ms 防抖；纯字母走本地首拼（≤50ms 先上屏）+ API 并行；中文走 API `wd`。
- 结果按类型分段（电影/剧集/动漫/综艺/海外/直播）并显示各类命中数；标题命中高亮，首拼命中附注拼音；跨源同片合并角标「N 源可用」。
- 空结果页给「换个词试试」+ 热搜词 chips。

### 3.8 播放源管理页

- 列表：源名 / 类型（MacCMS / m3u / bundle）/ 状态灯（在线绿、降级黄、离线红）/ 延迟 ms / 优先级。
- 操作：添加（粘贴 JSON / 选本地文件 / 填远程 URL）、测试连通、启用/停用、上移下移（改 priority，数值小优先）、删除、重新校验。
- 导入失败必须显示 `tools/validate_sources.py` 同源的错误码（E_xxx）+ 中文原因 + 出错字段路径。

## 4. D-pad 交互映射

| 场景 | 按键 | 行为 |
| --- | --- | --- |
| 全局 | `BACK` | 逐级返回；首页再按一次弹「退出应用」二次确认 |

| 播放器 | `MENU` | 呼出切源面板 |
| 直播 | `CH+/CH-`、`UP/DOWN` | 切台 |
| 任意 | `ENTER/OK` | 确认 |

## 6. 落地约束（给 engineer 的硬要求）

1. 所有颜色/字号/圆角走 `TvTheme` 单一数据源，不得在组件内写死十六进制。
2. 模式切换只在 `TvTheme` 与 `HomeContent` 分派处发生，业务层无感知。
3. Hero 只有一张大图，且必须先 `Precision.EXACT` 加载后再淡入（不做模糊占位）。
4. 列表项 Composable 必须接受稳定 key，禁止在 item 内创建 ImageLoader / OkHttp client。
5. 焦点管理统一走 `FocusRequester` + `focusProperties`，禁止 `onKeyEvent` 里手动改坐标。
6. C 模式禁止引入任何 `animate*`、`shadow`、`blur`、`Brush.linearGradient` 大面积绘制。
