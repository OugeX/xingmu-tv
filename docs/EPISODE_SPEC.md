# 选集 · 多源换源 · 海外板块规格

## 1. 海外板块（韩剧 / 美剧 / 国外节目）

首页与左侧导航新增一级入口 **「海外」**，下设：

| 分区 | 取数 |
| --- | --- |
| 韩剧 | 各源 `韩国剧 / 韩剧` 子分类（`assets/overseas_map.json` 已按源记录 typeId） |
| 美剧 | `欧美剧 / 美剧 / 美国剧` 子分类 |
| 日剧 / 泰剧 / 港台剧 | 对应子分类 |
| 海外综艺 | `欧美综艺 / 日韩综艺 / 港台综艺` |
| 海外动漫 | `日韩动漫 / 欧美动漫 / 海外动漫` |

- 已内置 7 个实测可用源（`assets/sources.builtin.json`，2026-10-21 探测）：暴风资源(主)、非凡资源、电影天堂资源、量子资源、百度资源、光速资源、最大资源 —— **每个源都带韩国剧/欧美剧子分类**。
- 首次启动自动装载内置源；用户也可在「播放源管理 → 内置目录」随时重新启用。
- 海外板块的聚合列表按「作品指纹」跨源合并，同一部剧只出现一次，卡片角标显示「N 个源可用」。

## 2. 选集：要好按、要好找

### 2.1 详情页选集

| 能力 | 规则 |
| --- | --- |
| 布局 | 网格 chips，每行 8 个（1080p）/ 6 个（720p），`200×80dp`，焦距焦点 3dp 金色描边 |
| 大剧集折叠 | >60 集时按 30 集分页签（`1-30 / 31-60 / 61-90`），避免长列表滚动耗时 |
| 排序 | 默认正序，右上角可切「倒序」（追更用户看最新集） |
| 状态标记 | 已看集数打勾 ✓；当前集金色底；未更新集显示「待更新」且不可点 |
| 快捷操作 | 长按 OK 弹「从第 N 集播放 / 复制集名 / 标记已看」 |
| 更新提示 | 追更剧显示「更新至第 N 集 / 全 N 集」 |

### 2.2 播放中选集（不退出播放）

- `DPAD_DOWN` 两次 或 `MENU` → 弹出半屏选集面板（底部抽屉，播放器继续走，不黑屏）。
- 面板内左右选页、上下选集，`OK` 立即切集：`setMediaItem + prepare`，复用同一个 ExoPlayer 实例（不重建，切换 ≤800ms）。
- 遥控器 `<` `>` 键 = 上一集 / 下一集。
- 连播开关（默认开）：本集结束前 15 秒预加载下一集首片；播完自动切下一集，切集时保留倍速与画面比例。

## 3. 多源同片：丝滑换源

### 3.1 聚合口径

同片判定（三级，命中即合并）：

1. 规范化标题 + 年份：标题去「第X季 / 全集 / HD / 国语 / 粤语 / 中字」等噪声后完全相等，且 `vod_year` 相同。
2. 标题相似度 ≥0.92（编辑距离归一化）+ 年份相同 + 主分类相同。
3. 手动合并：用户在详情页点「这不是同一部」可拆开，或点「合并到某作品」可手动并。

### 3.2 换源面板

- 入口：详情页「切换源」按钮、播放中 `MENU` → 「线路」页签。
- 每行显示：源名 / 画质（实测分辨率）/ 延迟 ms / 该源集数 / 状态灯 / 是否含烧录广告。
- **集数对齐**：自动把当前集号映射到目标源同集号；目标源缺该集 → 该行置灰并标注「缺第 N 集」。
- 一键切换，切换后保持：当前集、播放位置、倍速、画面比例、字幕/音轨选择。

### 3.3 切换如何做到"不卡不黑"

```
1. 新建 MediaItem（目标源同集 URL）→ player.setMediaItem + prepare（旧内容继续播）
2. 监听 onPlaybackState == READY 或首帧渲染回调
3. 校验位置：绝对 position 偏差 <2s 直接用；否则按 (pos / duration) 比例落到新源
4. 淡出 200ms → switchSurface/换源 → seekTo(位置) → 淡入
5. 任一步失败：保留旧播放器继续播，提示「切换失败，已留在原线路」
```

- 全程复用同一 `ExoPlayer` 与 `SurfaceView`，不重建 surface（避免黑屏 1-2 秒）。
- 切换中显示右上角小胶囊「正在切换线路…」，2 秒内完成无感。
- **自动容错**：播放器报错 / 连续 8 秒无数据 / 分片 3 次 404 → 自动按 priority 尝试下一个源的同集同位置，成功则提示「已切换到《源名》」，全失败才报错。

### 3.4 记忆

- 每部作品记住「上次成功的源 + 集号 + 位置」，下次进入优先用该源；
- 该源失效（连续两次失败）自动降权，改用备用源并记录日志。

## 4. 验收

| 项 | 标准 |
| --- | --- |
| 海外入口 | 首页/导航有「海外」，韩剧、美剧列表有数据（来自内置 7 源） |
| 选集 | 60 集以上分页、倒序、已看标记、播放中不退出切集 ≤800ms |
| 换源 | 同片跨源合并；缺集置灰；换源保持集号+位置+倍速；失败自动回到旧线路 |
| 自动容错 | 断开当前源可自动切到备用源并续播 |
